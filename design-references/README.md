# design-references/

Drop screenshots of apps, sites, or dashboards whose look you like into this folder,
then ask the **ui-ux-designer** agent to "review the images in `design-references/`
and update `DESIGN.md`." Claude Code reads image files directly and distills them into
the token-based design system both surfaces follow. From then on, every UI step reads
`DESIGN.md`, not the images — that's what keeps the extension and dashboard consistent.
